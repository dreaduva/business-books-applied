# Obviously Awesome Worked Example

**Fictional teaching example.** All organizations, participants, numbers, and outcomes are invented for this exercise, not reported results or a case from the book.

## Buyer and current alternative

LessonLoop is a fictional confirmation tool for independent tutors. Working hypothesis: tutors coordinating frequent changes manually have more need than tutors with fixed schedules. Invented interview notes describe one tutor using a spreadsheet plus messages; another uses an existing booking platform. Neither note establishes market prevalence.

## Capability to value

Prototype capability: show pending confirmations in one list. Compared with searching message threads, the intended benefit is easier identification of unresolved changes. The prototype can display the list; time saved is unknown. “Fewer no-shows” is excluded because the prototype does not establish attendance outcomes.

## Best-fit and poor-fit customers

Proposed best fit: a solo tutor managing several changing lesson times without a confirmation view. Poor fit: a tutoring center needing payroll, or a tutor whose existing platform already solves confirmation tracking. Prospect screening asks about the actual routine rather than assuming every tutor needs the product.

## Category candidates

Candidate A: tutoring management platform, which suggests billing and student records the product lacks. Candidate B: lesson-confirmation tracker, which more closely describes the prototype. Choose B provisionally. Explain that it tracks confirmations and does not book lessons or collect payment.

## Brief and next evidence

For independent tutors coordinating changing lesson times through messages, LessonLoop is a lesson-confirmation tracker that brings unresolved confirmations into one view. Unlike manually checking separate threads, it displays a pending list. Next: observe whether this view helps a tutor complete a real confirmation routine. Revise the segment if tutors with changing schedules already have adequate tools; revise the category if people consistently expect automatic booking.
