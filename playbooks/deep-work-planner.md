# Focused Work Plan Playbook

[Home](../README.md) · [Book guide](../books/deep-work/README.md) · [Worksheet](../books/deep-work/worksheet.md)

## 1. Choose the result

Name one difficult artifact or decision and the first action that advances it. Gather the required inputs.

## 2. Find a feasible window

Inspect real obligations. Choose a duration that fits and reduce the scope if necessary. Arrange coverage only through the normal authorized process.

## 3. Prepare the session

Open the required materials, reduce unrelated distractions, and define what can legitimately interrupt. Keep a simple place to capture unrelated tasks.

## 4. Work and preserve context

Advance the defined output. When an essential interruption occurs, leave a brief resume note where possible. Do not count planning a session as completing it.

## 5. Close and review

Save the work, mark what remains incomplete, and return to ordinary responsibilities. Compare the planned block with actual output and interruptions. Change the next session's scope or timing based on that evidence.
