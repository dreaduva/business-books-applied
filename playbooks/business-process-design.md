# Repeatable Process Brief Playbook

[Home](../README.md) · [Book guide](../books/the-e-myth-revisited/README.md) · [Worksheet](../books/the-e-myth-revisited/worksheet.md)

## 1. Select a recurring source of friction

Choose one bounded task the business already performs. State its trigger and desired output.

## 2. Observe and write the ordinary path

Record the actions and decisions, required information, and access. Mark proposed improvements separately from the current workflow.

## 3. Add quality and exceptions

Define evidence of completion. Name the conditions that require a pause or escalation, with an accountable owner.

## 4. Try the handoff

Start with a desk walkthrough. If authorized and appropriate, let a trained operator try the process and record every missing instruction or ambiguous decision. Do not call a simulation a production test.

## 5. Revise and assign ownership

Update the unclear steps, keep a version, and set a review trigger. The owner should be able to explain what changed and why. Use the procedure to support judgment rather than forcing unusual cases through the ordinary path.

## Verify an exception before calling the procedure usable

Run a supplied normal case and a plausible missing-input case through the written steps. Record where the operator had to guess. Add the missing decision, keep ownership explicit through acceptance and rerun the affected case. A blocked task should say who can unblock it and what can continue meanwhile. Report the walkthrough as simulated unless real authorized work was observed.
