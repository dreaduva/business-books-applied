# Habit Experiment Plan Playbook

[Home](../README.md) · [Book guide](../books/atomic-habits/README.md) · [Worksheet](../books/atomic-habits/worksheet.md)

## 1. Choose a useful action

Write the result you want and the smallest observable behavior that supports it. Start with one routine.

## 2. Place it in the day

Identify a reliable cue and prepare the materials. Remove one specific source of friction rather than redesigning the whole environment.

## 3. Define completion and recovery

State what counts as a useful repetition and what happens after a miss. Keep feedback simple and non-punitive.

## 4. Observe real opportunities

Record whether the action occurred when its cue appeared and what got in the way. Note whether its output was useful later.

## 5. Change one thing

Review the pattern and adjust the cue, action size, or environment. Keep the routine only if it helps. A trial's end is a review point, not a guarantee that the behavior is now automatic.

## Inspect an output before praising the streak

At review, reconstruct the opportunity count and examine at least one actual output. Separate repetition from usefulness. If the cue is absent, redesign timing; if the note is vague, improve the minimum quality criterion. Preserve the historical rule when changing the plan. A missed action calls for a workable recovery, not invented completion or a doubled workload.
