# Channel result decisions

Reconstruct counts before ranking. Use the same event definition and comparable cohort maturity. Show cash, hours, an optional stated labor valuation, and cost per named outcome. A respondent is not automatically a customer.

When a cheap lead source loses downstream, explain which qualification or activation difference reverses the ranking. Do not use revenue projections to fill absent paid-customer data.

Inspect repeatable access and capacity. A one-off host favor does not establish a scalable partnership channel. If delivery support differs, retain it as a competing explanation rather than attributing everything to audience quality.

If tracking is broken, identify the broken measurement and salvage only supported observations. If SEO has had two days while ads have a mature follow-up window, do not declare SEO inferior; state the short-window learning and schedule an appropriate review.

Deliver a bounded allocation: question, audience, offer, access prerequisite, cap, measurement, review window, stop/repeat condition and uncertainty. Existing user constraints take precedence over any example's numbers.
