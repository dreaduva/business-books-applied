# Startup Experiment Plan: Method and Judgment

## Test design

Ask what result would change the decision. An activity metric is useful only when linked to the assumption. Record exclusions and missing observations rather than silently removing inconvenient events. Compare equivalent units; visits, people, accounts, and transactions are not interchangeable.

## Interpretation

A before/after difference may have alternative causes. Small, selected samples can reveal a failure mode without estimating its market frequency. If a metric improves while the guardrail fails, show both. Report “not run” for a proposed experiment and “inconclusive” when the evidence cannot separate explanations.

## Repair checks

If the proposed test requires a finished platform, find a smaller intervention that tests the same assumption. If it instead tests a different assumption, say so. Do not set numeric success thresholds on behalf of the user without labeling them as proposals and explaining their decision relevance.
