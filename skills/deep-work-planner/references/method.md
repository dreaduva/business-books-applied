# Focused Work Plan: Method and Judgment

## Output makes time interpretable

A calendar block is an allocation, not an accomplishment. Name the artifact or decision it should advance and the boundary of the task. If an unknown input prevents the decision, identifying that dependency can be a useful result; record the output as incomplete where appropriate.

## Respect the operating context

Customer service, care duties, and on-call work change what protection is possible. Negotiate coverage or use a smaller window where appropriate. A focus plan must not silently cancel commitments or hide urgent channels.

## Distinguish interruption types

An avoidable inbox check and an actual incident need different responses. Capture routine distractions briefly. For an essential interruption, preserve enough context to resume without pretending the interruption should not have happened.

## End deliberately

Save the artifact, record unresolved questions, and identify the next physical action. Repeated overruns suggest a scope or scheduling problem. Avoid turning focused work into an instruction to eliminate breaks or work indefinitely. Review quality and progress alongside duration, with no universal productivity multiplier.
