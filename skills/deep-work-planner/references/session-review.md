# Review sessions by constraints and output

Reconstruct fixed commitments before judging the plan. Check start/end arithmetic, overlap, transitions, working hours and support/on-call obligations. Coverage is a supplied fact or an unresolved dependency, not an assumption to hide.

Compare planned minutes with actual focused minutes, interruption time and resulting artifact. Do not count incident response as focus on the original task or call legitimate duty a personal failure. If a block was interrupted, record the actual work and resume point.

Inspect the artifact against acceptance criteria. A finished introduction is not a completed decision memo. When time is spent but the core answer is missing, prioritize the missing reasoning and reduce polish or scope before prescribing longer hours.

Choose remedies matched to the evidence: prepare missing inputs; move overlapping blocks; retain required tools; capture unrelated tasks; write a specific resume note. Preserve ordinary work and rest instead of allocating hidden catch-up time.

Return a revised schedule, total minutes, changed scope, first actions, interruption boundary, shutdown note and uncertainty. A feasible proposed plan is not an observed productivity gain. Calendar edits or device-setting changes need their own task authorization.
