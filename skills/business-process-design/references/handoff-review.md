# Handoff review

For a supplied incident, reconstruct trigger, input packet, operator knowledge, procedure version, decision made and output. Separate a missing rule from missing training or access. “Be more careful” does not repair an undocumented decision.

A normal case tests the operating path; an exception tests whether the operator pauses or routes work correctly. Define ownership until the handoff is accepted. If the next owner is unknown, retain an open decision instead of inventing a department.

Revise the smallest relevant rule and rerun the affected case using only supplied facts. A missing time zone remains unknown until an authorized source provides it. A request is not a confirmation. A supported capability is not the same as a customer's requested feature.

Return revised steps, acceptance evidence, blocker states, the observed or simulated rerun and remaining limitations. Clearly distinguish a desk simulation from a live trial. The procedure must not imply authorization to send messages, change access or operate a production system simply to test it.

Review quality and active work separately from waiting. A process that pauses for a material missing input may be more reliable even when its elapsed time increases.
