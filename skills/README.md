# AI Skills for Business Tasks

[Home](../README.md) · [Books](../books/README.md) · [Playbooks](../playbooks/README.md)

These skills give an assistant a focused procedure and quality checks. They work from the information you supply; they do not replace customer research or create evidence.

| Skill | Bring | Get |
| --- | --- | --- |
| [Customer Interview Planner](customer-interview-planner/SKILL.md) | Your idea, customer segment, assumptions, and any real notes | A conversation plan and an evidence log |

## Use a skill

Open the skill file and read it before using it. If your assistant supports a `SKILL.md` format, follow that assistant's documented import or installation procedure and include the skill's `assets` folder. Otherwise, provide the instructions as context and explain your task in your own words.

The files use the [Agent Skills format](https://agentskills.io/specification). No universal install command or compatibility with every assistant is claimed. Skills are original project resources, independent of book authors and publishers.
